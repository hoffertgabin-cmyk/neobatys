## Texte Instagram / Facebook

```
Une demande de devis arrive à 21 h. Le client a probablement écrit à deux ou trois artisans. Qui répond en premier ?

Une bonne première réponse, c'est :
- un merci ;
- les questions utiles : adresse du chantier, photos, délai souhaité ;
- la suite : quand vous passez, ou quand le devis arrive.

Notre assistant IA envoie cette première réponse en quelques minutes, même le soir, et vous transmet la demande avec les réponses du client. Vous reprenez la main pour le devis.

Démo gratuite : lien dans la bio.
```

Facebook : remplacer « lien dans la bio » par `www.neobatys.com/contact`.

## Texte LinkedIn

```
Dans le bâtiment, la vitesse de réponse à une demande de devis est souvent décisive : le client qui demande plusieurs devis retient en premier ceux qui lui répondent.

Pour une petite entreprise, répondre vite est difficile : les demandes arrivent pendant le chantier ou le soir.

Notre assistant de réponse aux demandes fait trois choses :
1. il remercie le client et confirme la prise en compte ;
2. il pose les questions utiles (adresse, photos, délai) ;
3. il transmet à l'artisan une demande complète, prête à chiffrer.

L'artisan garde la main sur le devis et sur la relation. L'assistant s'occupe des premières minutes.

Fin de nos 4 premières semaines sur LinkedIn : merci à celles et ceux qui nous ont lus. Vos questions orientent les prochains posts.

www.neobatys.com/contact
```
